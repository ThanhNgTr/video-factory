# @vf/script — A. learn and write

Turns a viral link into a formula, and a formula (+ idea, + series bible) into a story and a shot list.

| Stage               | Reads                                                                     | Writes                                      | Port                           |
| ------------------- | ------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------ |
| `ingest.download`   | `--url`                                                                   | `source.mp4`, `frames/*.jpg`, `source.json` | `VideoDownloader` (yt-dlp)     |
| `ingest.transcribe` | `source.mp4`                                                              | `transcript.json`                           | `Transcriber` (faster-whisper) |
| `ingest.formula`    | frames + transcript                                                       | `formula.json`                              | `Llm` (vision)                 |
| `ingest.format`     | frames + transcript + `formula.json`                                      | `format.json` (the genre, ADR 0017)         | `Llm` (vision)                 |
| `script.write`      | library, params (`format`, `series`, `idea`, `formula`, `choice`, `note`) | `script.json`, `script-review.json`         | `Llm`                          |
| `script.direct`     | `script.json`                                                             | `scene.json`                                | `Llm`                          |
| `script.bible`      | `script.json`                                                             | `series-bible.json`                         | —                              |

- Prompts: `prompts/*.md`, first line `<!-- version: N -->`; the stage version follows the prompt version, and the run cache keys on that number, not on the text: **any edit to a prompt needs a bump**, or old runs keep their cached output. Change a prompt → bump → `vf eval` (GĐ 3).
- A HUD (title, clock, counter) is a format choice: `Format.hud`, on only for `series`; `checkScriptRefs` refuses a HUD, clock or counter in a format without one, and `ingest.format` (prompt v3) turns it on only when the sample keeps a game-like overlay on screen.
- `script.write` first pitches five premises from five angles and picks one (`prompts/premise.md`, ADR 0023), with the studio's memory of finished videos (`library/premises/`, kept by `vf make`) as MADE BEFORE; it then writes that premise (`Script.premise`), then a critic (`prompts/review.md`, model `review`) judges the script against the criteria every short shares (since v2 also `visual`: every beat changes something seen, ADR 0022) plus the format's `rubric` (`library/formats/*.json`); a failing script is rewritten from the critic's fixes (`prompts/revise.md`) at most twice and the best draft is kept (ADR 0015). It never blocks: `script-review.json` records the verdict.
- An existing `script.json` (human edits) is only judged, never rewritten, unless the run has a `note`: `vf revise <run> --note "..."` rewrites the whole script from the producer's note, then the critic loop runs again and everything after it is remade.
- `script.direct` stages a series only in the bible's `sets` when the bible lists them (all sets otherwise). It also turns numbers, comparisons and steps into graphic shots and declares the icons the library lacks in `scene.icons` (prompt v7, ADR 0017). Stories that build something in the ground layer by layer become 3D dioramas (`Shot.diorama`, prompt v15, ADR 0021). Objects the action names become story props with the motion the action describes, weather becomes `fx`, and a narrator line about an object frames the prop (prompt v16, ADR 0022). The director also sets each shot's camera angle, lens, move, transition and J-cut and keeps the editing grammar `checkEditing` enforces: no two cuts to the same picture, red light for three shots at most, a tight last third, a host for explainers (prompt v20, ADR 0025). Every place opens with an establishing shot and the talk is broken by a silent cutaway (a prop, the room, the weather, a reaction) at least every 8 s; `checkSceneMatchesScript` allows two cutaways plus one per three lines (prompt v17).
- `ingest.download` also measures how the sample moves (`domain/motion.ts`, ADR 0024): per second a hard cut, the whole picture moving, the camera holding while things move (and where), or still; plus 6 fps filmstrips of the moments that move most (`motion.json`, `motion/strip-N.jpg`). `ingest.formula` and `ingest.format` get them with the stills, and the learned format's `staging` rules reach the director.
- `ingest.format` learns the sample's genre as a format (`checkLearnedFormat`: one-off `explainer` or `skit`, a speech budget the narrator can say). `vf ingest` saves formula and format under one id; `vf like <link> [--idea]` then makes a video with both. A script needs a formula only when one is given (a sample or a series).
- Checks that drive the repair loop: `checkScriptRefs`, `checkSceneRefs`, `checkSceneMatchesScript` in `@vf/contracts`. `checkSceneRefs` also rejects walks through furniture (ADR 0011). `checkSceneMatchesScript` makes wide, push, pan and shake shots show everyone in the beat's cast (ADR 0012). It also caps the shot count at one per line plus one per silent beat plus two, so inserts and reaction cuts replace shots instead of stretching the episode (ADR 0013). `checkSceneRefs` requires an `insert` shot's focus to hold an item.
- Swap providers in `apps/cli/src/wiring.ts`: `YtDlpDownloader` / `WhisperTranscriber` / `FakeDownloader` / `FakeTranscriber`.
